# Allimio 회원 서비스 이용 매뉴얼 (회원가입 · 로그인 · 계정 · 마이페이지 · 직원 초대)

이 문서는 Allimio(올리미오, all-im-io) AI CCTV 관제 서비스의 회원 관련 정책과 이용 방법을 질문-답변 형태로 정리한 안내서입니다. 각 항목은 독립적으로 읽어도 이해되도록 작성되었습니다.

---

## 0. 어디서 하나요? (회원 기능 위치 안내)

### Q. 회원 기능은 각각 어디서 하나요? (위치 한눈에 보기)
| 하고 싶은 일 | 위치 | 주소 |
|---|---|---|
| 로그인 | 메인 화면 상단 [데모 신청] 버튼(로그인 전) → 로그인 화면 | /login |
| 회원가입 | 로그인 화면 하단 [회원가입] 링크 | /singup |
| 아이디 중복 확인 | 회원가입 화면 아이디 칸 옆 [중복 확인] | /singup |
| 내 정보 조회·수정 | 왼쪽 메뉴 맨 아래 [마이페이지] → [수정] | /user/mypage |
| 비밀번호 변경(로그인 상태) | 마이페이지 비밀번호 항목 [비밀번호 변경] | /user/mypage |
| 비밀번호 재설정(분실) | 비밀번호 재설정 메일의 [비밀번호 재설정하기] 버튼 | 메일 링크 |
| 프로필 사진 등록·삭제 | 마이페이지 상단 프로필 이미지 영역 | /user/mypage |
| 로그아웃 | 왼쪽 메뉴 맨 아래 [로그아웃] | - |
| 직원 초대코드 발급(점주) | 왼쪽 메뉴 [회원 초대] → [초대하기] | /user/invite |
| 초대코드 입력(직원) | 왼쪽 메뉴 [회원 초대] → [수락하기] | /user/invite |
| 아이디 찾기·탈퇴·정지 해제 | 고객센터 1:1 문의 (상단 [문의하기]) | /user/qa/new |

### Q. 로그인 후 화면은 어떻게 구성되어 있나요? (메뉴 위치)
로그인하면 사용자 관리 화면(주소 /user)으로 들어갑니다.
- 왼쪽 메뉴(사이드바): 매장 목록, CCTV, 이슈, 손님 내역, 캘린더, 도면, 알림, 회원 초대 등 기능 메뉴가 있습니다. 사이드바 맨 아래에 [마이페이지]와 [로그아웃]이 있습니다. 모바일에서는 상단의 메뉴 버튼(전체 메뉴 열기)을 눌러 사이드바를 엽니다.
- 상단 바: 현재 선택한 매장 이름이 표시되고, 누르면 내 매장 목록이 펼쳐져 바로 다른 매장으로 전환할 수 있습니다. 목록 아래 [매장 전체 관리]를 누르면 매장 목록 화면으로 이동합니다.
메뉴에서 기능을 찾기 어려우면 아래 "어디서 하나요" 항목의 주소를 브라우저 주소창에 입력해도 됩니다. 로그인하지 않은 상태에서 /user 주소로 들어가면 로그인 화면으로 이동합니다.

### Q. 로그인 화면은 어디 있나요?
메인 화면 상단의 [데모 신청] 버튼을 로그인하지 않은 상태에서 누르면 로그인 화면(/login)으로 이동합니다. 로그인이 필요한 화면(/user로 시작하는 주소)에 들어가려고 해도 자동으로 로그인 화면으로 이동합니다. 주소창에 /login 을 직접 입력해도 됩니다.

### Q. 회원가입 화면은 어디 있나요?
로그인 화면(/login) 하단의 [회원가입] 링크를 누르면 "신규 회원가입" 화면(/singup)으로 이동합니다.

### Q. 마이페이지는 어디 있나요?
로그인 후 왼쪽 메뉴(사이드바) 맨 아래의 [마이페이지]를 누르면 이동합니다(/user/mypage). 내 정보 수정, 비밀번호 변경, 프로필 이미지 변경을 모두 여기서 합니다.

### Q. 비밀번호 변경은 어디서 하나요?
로그인한 상태라면 [마이페이지] → 비밀번호 항목의 [비밀번호 변경] 버튼에서 합니다. 비밀번호를 잊어 로그인할 수 없다면 비밀번호 재설정 메일을 받아 메일 안의 [비밀번호 재설정하기] 버튼으로 새 비밀번호를 설정합니다.

### Q. 로그아웃 버튼은 어디 있나요?
로그인 후 왼쪽 메뉴(사이드바) 맨 아래 [마이페이지] 옆(아래)에 [로그아웃]이 있습니다. 모바일에서는 상단 메뉴 버튼으로 사이드바를 연 뒤 누릅니다. 브라우저 탭을 닫아도 로그아웃됩니다.

### Q. 회원 초대(직원 초대)는 어디서 하나요?
로그인 후 왼쪽 메뉴의 [회원 초대](/user/invite) 화면에서 합니다. 점주는 [초대하기]로 매장을 골라 초대코드를 발급하고, 직원은 [수락하기]로 받은 6자리 코드를 입력합니다.

### Q. 탈퇴, 아이디 찾기, 계정 정지 문의는 어디서 하나요?
화면에서 직접 할 수 있는 메뉴가 없으므로 고객센터 1:1 문의로 요청합니다. 메인 화면 상단의 [문의하기] 버튼을 누르면 문의 작성 화면으로 이동합니다(로그인 상태: /user/qa/new, 로그인 전: /board/qa/new). 상단 [고객센터]에서 공지사항과 자주 묻는 질문도 볼 수 있습니다.

## 1. 회원가입

### Q. 회원가입은 어디서 하나요?
회원가입은 로그인 화면 하단의 [회원가입] 링크를 누르면 이동하는 "신규 회원가입" 화면에서 진행합니다. 회원가입은 무료이며, 로그인하지 않은 상태에서 누구나 가입할 수 있습니다. 가입이 완료되면 "회원가입이 성공적으로 완료되었습니다." 안내가 표시되고 메인 화면으로 이동합니다. 이후 로그인 화면에서 가입한 아이디와 비밀번호로 로그인하면 됩니다.

### Q. 회원가입할 때 무엇을 입력해야 하나요? (필수 항목)
회원가입 시 아래 항목은 모두 필수입니다.
- 아이디: 로그인할 때 사용하는 고유한 아이디 (최대 20자). 반드시 [중복 확인]을 거쳐야 합니다.
- 비밀번호: 8자 이상
- 비밀번호 확인: 위 비밀번호와 동일하게 입력
- 이름: 성함 (최대 20자)
- 이메일 주소: 비밀번호 재설정 안내 메일을 받는 주소이므로 실제 사용하는 이메일을 입력해야 합니다. (최대 50자)
- 연락처: 휴대폰 번호 (예: 010-0000-0000)
- 우편번호 / 기본 주소: [우편번호 검색] 버튼으로 주소를 검색하면 자동 입력됩니다.
- 상세 주소: 동·호수 등 (예: 101동 202호)
- 국가: 목록에서 선택 (기본값 대한민국)
- 서비스 이용 약관 동의, 개인정보 수집 및 이용 동의: 두 가지 모두 동의해야 가입할 수 있습니다.

### Q. 가입할 때 선택할 수 있는 국가(국적)는 어떤 것이 있나요?
대한민국, 미국, 일본, 중국, 베트남, 필리핀, 태국, 인도네시아, 대만, 캐나다, 영국, 독일, 프랑스, 호주 중에서 선택할 수 있습니다. 기본값은 대한민국입니다.

### Q. 아이디 중복 확인은 어떻게 하나요?
회원가입 화면에서 아이디를 입력한 뒤 아이디 입력칸 옆의 [중복 확인] 버튼을 누릅니다.
- "사용 가능한 아이디입니다." → 해당 아이디로 가입할 수 있습니다.
- "이미 사용 중인 아이디입니다. 다른 아이디를 입력해주세요." → 다른 아이디를 입력하고 다시 확인해야 합니다.
중복 확인을 하지 않고 [가입하기]를 누르면 "아이디 중복 확인을 진행해주세요." 안내가 나옵니다.

### Q. 중복 확인을 했는데 다시 하라고 나와요.
중복 확인을 마친 뒤 아이디를 한 글자라도 수정하면 확인 상태가 초기화됩니다. 아이디를 바꾼 경우에는 [중복 확인]을 다시 눌러 주세요.

### Q. 비밀번호 규칙이 있나요?
비밀번호는 8자 이상이어야 합니다. 8자 미만이면 "비밀번호가 8자 미만입니다." 안내가 표시됩니다. 비밀번호 확인란에 입력한 값이 다르면 "비밀번호와 확인이 일치하지 않습니다."가 표시됩니다. 비밀번호는 암호화되어 저장되므로 운영자도 원래 비밀번호를 확인할 수 없습니다.

### Q. 주소 입력이 안 돼요 / 우편번호 검색 창이 안 떠요.
기본 주소와 우편번호는 직접 입력하는 방식이 아니라 [우편번호 검색] 버튼을 눌러 주소를 검색·선택하면 자동으로 채워집니다. "우편번호 서비스 라이브러리가 로드되지 않았습니다." 안내가 나오면 주소 검색 서비스를 불러오지 못한 것이므로 페이지를 새로고침한 뒤 다시 시도해 주세요. 광고 차단 프로그램이 주소 검색 창을 막는 경우도 있습니다. 상세 주소는 직접 입력합니다.

### Q. 약관에 동의하지 않으면 가입할 수 없나요?
네. 서비스 이용 약관 동의와 개인정보 수집 및 이용 동의는 모두 필수입니다. 동의하지 않으면 "서비스 이용 약관에 동의해주세요." 또는 "개인정보 수집 및 이용에 동의해주세요." 안내가 나오고 가입이 진행되지 않습니다.

### Q. 회원가입 중 오류가 발생했다고 나와요.
"회원가입 중 오류가 발생했습니다. 입력 정보를 확인해주세요." 안내가 나오면 다음을 확인해 주세요.
- 모든 필수 항목을 입력했는지
- 입력값이 너무 길지 않은지 (아이디·이름 20자, 이메일 50자, 주소 100자 이내)
- 아이디 중복 확인 후 다른 사람이 먼저 같은 아이디로 가입하지 않았는지
문제가 계속되면 고객센터 1:1 문의로 연락해 주세요.

### Q. 회원가입하면 바로 서비스를 쓸 수 있나요?
가입하면 일반 회원(등급 6)으로 등록되고 바로 로그인할 수 있습니다. 로그인하면 구독권(요금제) 안내 화면으로 이동합니다. 매장 CCTV 관제 기능을 이용하려면 구독권을 구매해 점주(등급 10)가 된 뒤 매장을 등록해야 합니다. 이미 구독 중인 매장의 직원이라면 점주에게 받은 초대코드로 매장에 합류할 수 있습니다. (아래 "직원 초대" 항목 참고)

### Q. 회원가입 시 어떤 개인정보를 수집하나요?
아이디, 비밀번호(암호화 저장), 이름, 이메일, 연락처, 우편번호·주소·상세주소, 국가, 약관 및 개인정보 이용 동의 여부, 가입일시를 수집합니다. 또한 보안을 위해 로그인 시도 기록(시도한 아이디, 일시, 성공/실패 결과, 접속 IP 주소)과 회원정보 변경 기록(변경 항목, 변경 전·후 값, 변경 일시)이 저장됩니다. 비밀번호 변경 기록에는 실제 비밀번호 값이 저장되지 않습니다.

### Q. 한 사람이 여러 계정을 만들 수 있나요?
아이디는 중복될 수 없지만, 서로 다른 아이디로 여러 계정을 만드는 것 자체는 제한하지 않습니다. 다만 구독·매장 정보는 계정별로 관리되므로 하나의 계정으로 이용하는 것을 권장합니다.

## 2. 로그인 · 로그아웃

### Q. 로그인은 어떻게 하나요?
메인 화면 상단의 [데모 신청] 버튼(로그인 전)을 누르거나 주소창에 /login 을 입력해 로그인 화면으로 이동한 뒤, 가입한 아이디와 비밀번호를 입력하고 [로그인] 버튼을 누릅니다. 비밀번호 입력 후 Enter 키를 눌러도 로그인됩니다. 로그인에 성공하면 "로그인에 성공했습니다!" 안내 후 구독권 안내 화면으로 이동합니다.

### Q. 아이디 저장 기능이 있나요?
네. 로그인 화면의 [아이디 저장]을 체크하고 로그인하면 아이디가 저장됩니다. 체크하지 않으면 저장되지 않습니다.

### Q. 로그인이 안 돼요. "아이디 또는 비밀번호가 일치하지 않습니다"라고 나와요.
다음을 확인해 주세요.
1. 아이디와 비밀번호를 정확히 입력했는지 (대소문자, Caps Lock, 앞뒤 공백)
2. 가입한 아이디가 맞는지
3. 비밀번호를 최근에 변경했다면 새 비밀번호로 입력했는지
보안을 위해 아이디가 없는 경우와 비밀번호가 틀린 경우 모두 같은 안내 문구를 보여드립니다. 비밀번호가 기억나지 않으면 비밀번호 재설정을 이용해 주세요. 이용 정지 또는 탈퇴 처리된 계정도 로그인할 수 없습니다.

### Q. 아이디 또는 비밀번호를 입력하지 않았다고 나와요.
아이디 칸이 비어 있으면 "아이디를 입력해주세요.", 비밀번호 칸이 비어 있으면 "비밀번호를 입력해주세요."가 표시됩니다. 해당 칸을 입력한 뒤 다시 시도해 주세요.

### Q. "서버 연결에 실패했습니다"라고 나와요.
서비스 서버와 연결되지 않은 상태입니다. 인터넷 연결을 확인하고 잠시 후 다시 시도해 주세요. 계속 같은 안내가 나오면 일시적인 서버 점검일 수 있으니 고객센터로 문의해 주세요.

### Q. 정지되었거나 탈퇴한 계정은 로그인할 수 있나요?
아니요. 관리자에 의해 이용 정지된 계정은 "정지된 회원입니다.", 탈퇴 처리된 계정은 "탈퇴한 회원입니다."로 로그인이 거부됩니다. 정지 사유 확인이나 해제 요청은 고객센터 1:1 문의로 해 주세요.

### Q. 로그인 상태는 얼마나 유지되나요? 자꾸 로그아웃돼요.
로그인 정보는 브라우저 탭(세션)에 저장됩니다. 따라서
- 브라우저나 탭을 닫으면 자동으로 로그아웃됩니다. 다시 접속하면 로그인해야 합니다.
- 서비스를 이용하는 동안에는 로그인이 자동으로 연장됩니다.
- 로그인 후 최대 14일이 지나면 보안을 위해 다시 로그인해야 합니다.
- 로그인 연장에 실패하면 자동으로 로그인 화면으로 이동합니다.
다른 기기나 다른 브라우저에서 로그인하면 이전 로그인 상태가 해제될 수 있습니다.

### Q. 로그아웃은 어떻게 하나요?
로그인 후 화면 왼쪽 메뉴(사이드바) 하단의 [로그아웃] 버튼을 누르면 로그아웃되고 로그인 화면으로 이동합니다. 공용 PC에서는 사용 후 반드시 로그아웃하거나 브라우저를 닫아 주세요.

### Q. 다른 사람이 내 계정으로 로그인한 것 같아요.
즉시 마이페이지에서 비밀번호를 변경해 주세요. 비밀번호를 변경한 뒤에도 의심스러운 점이 있으면 고객센터 1:1 문의로 알려 주세요. 서비스는 모든 로그인 시도의 일시와 접속 IP를 기록하고 있어 관리자가 확인할 수 있습니다.

### Q. 관리자 로그인과 회원 로그인은 다른가요?
네. 일반 회원은 서비스 메인의 로그인 화면을 이용하고, 운영 관리자는 별도의 관리자 전용 로그인 화면을 이용합니다. 일반 회원 계정으로는 관리자 화면에 로그인할 수 없습니다.

## 3. 아이디 · 비밀번호 찾기

### Q. 비밀번호를 잊어버렸어요. 어떻게 재설정하나요?
비밀번호는 이메일 인증 방식으로 재설정합니다.
1. 비밀번호 찾기(재설정) 화면에서 아이디와 가입 시 등록한 이메일을 입력합니다.
2. 아이디와 이메일이 일치하면 "가입하신 이메일로 비밀번호 재설정 링크가 발송되었습니다" 안내가 나오고, "[all-im-io] 비밀번호 재설정 안내" 제목의 메일이 발송됩니다.
3. 메일의 [비밀번호 재설정하기] 버튼을 눌러 새 비밀번호를 설정합니다.
4. "비밀번호가 성공적으로 변경되었습니다. 새 비밀번호로 로그인해 주세요." 안내가 나오면 새 비밀번호로 로그인합니다.

### Q. 비밀번호 재설정 링크는 언제까지 유효한가요?
재설정 링크는 발송 시점부터 30분 동안 유효하며, 한 번 사용하면 다시 사용할 수 없습니다. 30분이 지나면 "만료된 링크입니다. 재설정 요청을 다시 진행해 주세요." 안내가 나오므로 재설정을 다시 요청해 주세요. 재설정을 여러 번 요청하면 가장 마지막에 받은 메일의 링크만 유효합니다.

### Q. "아이디 또는 이메일 정보가 일치하지 않습니다"라고 나와요.
입력한 아이디와 이메일이 가입 정보와 서로 맞지 않는 경우입니다. 가입할 때 등록한 이메일 주소인지 확인해 주세요. 이메일을 변경한 적이 있다면 변경한 이메일을 입력해야 합니다.

### Q. 재설정 메일이 오지 않아요.
1. 스팸함·프로모션함을 확인해 주세요.
2. 입력한 이메일이 가입 시 등록한 이메일인지 확인해 주세요.
3. 몇 분 기다린 뒤에도 오지 않으면 재설정을 다시 요청해 주세요.
"메일 발송 중 오류가 발생했습니다. 잠시 후 다시 시도해 주세요." 안내가 나왔다면 메일 서버 오류이므로 잠시 후 다시 시도해 주세요.

### Q. "유효하지 않은 재설정 링크입니다"라고 나와요.
이미 사용한 링크이거나, 이후에 재설정을 다시 요청해 이전 링크가 무효가 된 경우입니다. 가장 최근에 받은 메일의 링크를 사용하거나 재설정을 새로 요청해 주세요.

### Q. 아이디를 잊어버렸어요.
현재 아이디 찾기 기능은 별도로 제공하지 않습니다. 고객센터 1:1 문의에 이름, 가입 이메일, 연락처를 남겨 주시면 본인 확인 후 안내해 드립니다.

## 4. 마이페이지 (내 정보 조회 · 수정)

### Q. 내 정보는 어디서 확인하나요?
로그인 후 메뉴의 [마이페이지]에서 확인할 수 있습니다. 마이페이지에서는 프로필 이미지, 아이디, 이름, 이메일, 연락처, 우편번호, 기본 주소, 상세 주소, 국적을 볼 수 있습니다.

### Q. 내 정보를 수정하려면 어떻게 하나요?
마이페이지에서 [수정] 버튼을 눌러 수정 모드로 전환한 뒤 원하는 항목을 바꾸고 [저장]을 누릅니다. 저장되면 "내 정보가 수정되었습니다." 안내가 나옵니다. 수정을 취소하려면 [취소]를 누르면 원래 값으로 돌아갑니다. 주소는 [우편번호 검색]으로 다시 검색해서 변경합니다.

### Q. 마이페이지에서 수정할 수 있는 항목은 무엇인가요?
직접 수정할 수 있는 항목: 이름, 이메일, 연락처, 우편번호, 기본 주소, 상세 주소, 비밀번호, 프로필 이미지.
직접 수정할 수 없는 항목: 아이디, 회원 등급, 계정 상태, 가입일. 이 항목은 변경이 필요하면 고객센터로 문의해 주세요. 국적 변경도 고객센터로 문의해 주세요.

### Q. 아이디를 바꿀 수 있나요?
아니요. 아이디는 가입 후 변경할 수 없습니다. 다른 아이디를 사용하려면 새로 가입해야 하며, 이 경우 기존 계정의 구독·매장 정보는 이전되지 않습니다.

### Q. 정보 수정 시 빈칸으로 저장할 수 있나요?
아니요. 이름, 이메일, 연락처, 우편번호, 기본 주소, 상세 주소는 필수 항목이라 비워 둘 수 없습니다. 비어 있으면 "OO을(를) 입력해주세요." 안내가 나오고 저장되지 않습니다.

### Q. 이메일을 변경하면 어떻게 되나요?
이메일을 변경하면 이후 비밀번호 재설정 메일은 새 이메일로 발송됩니다. 비밀번호 재설정 시에도 새 이메일을 입력해야 하므로 반드시 실제 사용하는 이메일로 변경해 주세요.

### Q. "수정 중 오류가 발생했습니다"라고 나와요.
일시적인 오류일 수 있습니다. 새로고침 후 다시 시도해 주세요. 입력값이 너무 긴 경우(이름 20자, 이메일 50자, 주소 100자 초과)에도 저장되지 않을 수 있습니다. 계속되면 고객센터로 문의해 주세요.

### Q. 내 정보 변경 이력이 남나요?
네. 이름·연락처·이메일·주소·등급·상태가 변경되면 변경 항목, 변경 전 값, 변경 후 값, 변경 일시, 변경한 주체(본인 또는 관리자)가 기록됩니다. 비밀번호 변경은 변경 사실만 기록되고 비밀번호 값은 기록되지 않습니다.

## 5. 비밀번호 변경 (로그인 상태)

### Q. 로그인한 상태에서 비밀번호를 바꾸려면?
마이페이지의 비밀번호 항목에서 [비밀번호 변경] 버튼을 누르면 변경 창이 열립니다.
1. 현재 비밀번호 입력
2. 새 비밀번호 입력 (8자 이상)
3. 새 비밀번호 확인 입력
4. [변경] 클릭 → "비밀번호 변경에 성공하였습니다." 안내
다음 로그인부터 새 비밀번호를 사용합니다.

### Q. 비밀번호 변경 시 "비밀번호가 일치하지 않습니다"라고 나와요.
현재 비밀번호를 잘못 입력한 경우입니다. 현재 비밀번호가 기억나지 않으면 로그아웃 후 비밀번호 재설정(이메일 인증)을 이용해 주세요.

### Q. 비밀번호 변경 시 다른 안내 문구가 나와요.
- "현재 비밀번호를 입력해주세요." → 현재 비밀번호 칸이 비어 있습니다.
- "비밀번호는 8자 이상이어야 합니다." → 새 비밀번호를 8자 이상으로 입력해 주세요.
- "비밀번호 확인이 일치하지 않습니다." → 새 비밀번호와 확인 값을 똑같이 입력해 주세요.
- "비밀번호 변경 중 오류가 발생했습니다." → 일시적인 오류입니다. 잠시 후 다시 시도해 주세요.

## 6. 프로필 이미지

### Q. 프로필 사진은 어떻게 등록하나요?
마이페이지 상단 프로필 이미지 영역에서 이미지를 선택하면 바로 업로드되어 적용됩니다. 등록되면 "프로필 이미지가 설정되었습니다." 안내가 나옵니다. 새 이미지를 올리면 기존 이미지는 자동으로 교체·삭제됩니다.

### Q. 어떤 파일을 프로필 이미지로 쓸 수 있나요?
JPG, JPEG, PNG, GIF, JFIF, WEBP 등 이미지 파일을 사용할 수 있습니다. 지원하지 않는 형식이면 "지원하지 않는 파일 형식이거나 저장에 실패했습니다." 안내가 나옵니다.

### Q. 프로필 이미지를 삭제하고 싶어요.
마이페이지 프로필 이미지 영역의 [삭제] 버튼을 누르고 확인 창에서 삭제를 확인하면 기본 이미지로 돌아갑니다. 등록된 이미지가 없을 때는 삭제 버튼이 비활성화되며, "삭제할 이미지가 없습니다." 안내가 나올 수 있습니다. 프로필 이미지가 없으면 이름 첫 글자가 기본 아바타로 표시됩니다.

## 7. 회원 등급 · 계정 상태

### Q. 회원 등급은 어떻게 나뉘나요?
- 관리자 등급(1~5): 서비스 운영 관리자 계정입니다.
- 일반 회원 등급(6~8): 서비스 이용 회원입니다. 신규 가입 시 기본 등급은 6입니다.
- 직원 등급(9): 매장 직원 회원입니다. 초대코드로 합류한 매장만 이용할 수 있습니다.
- 점주 등급(10): 구독권을 구매한 회원입니다. 일반 회원이 구독권 결제를 완료하면 자동으로 점주 등급으로 변경됩니다. 구독 취소·만료로 이용 중인 구독권이 하나도 남지 않으면 다시 일반 회원(6)으로 돌아갑니다.
등급은 회원이 마이페이지에서 직접 변경할 수 없습니다. 점주 등급은 구독권 구매로 자동 부여되며, 그 외 등급 변경은 관리자가 처리합니다.

### Q. 점주와 직원(일반 회원)은 무엇이 다른가요?
- 점주(등급 10): 본인이 등록한 매장을 소유하고 관리합니다. 매장 생성·수정·삭제, 직원 초대코드 발급, 매장 도면 등록·변경·삭제를 할 수 있습니다.
- 직원(초대코드로 합류한 회원): 합류한 매장만 볼 수 있습니다. CCTV 목록, CCTV 이슈 확인·정탐/오탐 처리, 손님 내역, 매장 캘린더를 이용할 수 있고, 매장 도면은 조회만 가능하며 직원 초대는 할 수 없습니다.
- 가입만 하고 구독권 구매나 초대코드 입력을 하지 않은 회원은 이용할 수 있는 매장이 없어 매장 목록이 비어 있습니다.

### Q. 구독권을 샀는데 점주 기능(직원 초대, 도면 등록)이 안 보여요.
구독권 결제 직후에는 결제한 화면에서 등급이 바로 반영됩니다. 다른 기기나 다른 브라우저 탭에서 이미 로그인해 있었다면 등급이 갱신되지 않았을 수 있으니 로그아웃 후 다시 로그인해 주세요. 그래도 점주 기능이 보이지 않으면 고객센터 1:1 문의로 결제 내역과 함께 알려 주세요.

### Q. 계정 상태에는 어떤 것이 있나요?
- 정상: 모든 서비스를 이용할 수 있습니다. 가입 시 기본 상태입니다.
- 이용 정지: 관리자가 운영 정책 위반 등의 사유로 이용을 정지한 상태입니다. 정지 사유가 함께 기록되며 로그인할 수 없습니다.
- 탈퇴: 탈퇴 처리된 상태로 로그인할 수 없습니다.

### Q. 계정이 정지됐어요. 이유가 뭔가요? 어떻게 풀 수 있나요?
계정 정지는 관리자가 사유를 기록하고 처리합니다. 정지 사유 확인과 해제 요청은 고객센터 1:1 문의로 해 주세요. 정지 해제는 관리자 검토 후 계정 상태를 정상으로 변경하는 방식으로 처리됩니다.

### Q. 회원 탈퇴는 어떻게 하나요?
현재 회원이 직접 탈퇴하는 메뉴는 제공하지 않습니다. 탈퇴를 원하시면 고객센터 1:1 문의로 요청해 주세요. 탈퇴 처리 시 회원 데이터는 즉시 삭제되지 않고 계정 상태만 탈퇴로 변경되어 로그인이 차단됩니다. 이용 중인 구독권이 있다면 탈퇴 전에 구독 해지·환불 여부를 먼저 확인해 주세요.

### Q. 탈퇴한 아이디로 다시 가입할 수 있나요?
탈퇴 처리된 계정의 정보는 삭제되지 않고 남아 있기 때문에 같은 아이디로는 다시 가입할 수 없습니다. 다른 아이디로 가입하거나, 기존 계정 복구를 고객센터에 문의해 주세요.

## 8. 매장 직원 초대 (초대코드)

### Q. 우리 매장 직원도 같이 쓸 수 있나요?
네. 점주가 초대코드를 발급해 직원에게 전달하면, 직원이 자신의 계정으로 로그인한 뒤 초대코드를 입력해 매장에 합류할 수 있습니다. 직원도 먼저 Allimio 회원가입이 되어 있어야 합니다. 메뉴의 [회원 초대]에서 이용합니다.

### Q. 초대코드는 어떻게 발급하나요? (점주)
초대코드는 점주(구독권을 구매한 회원, 등급 10)만 발급할 수 있습니다. 직원이나 구독권이 없는 회원은 초대코드 입력만 할 수 있습니다.
1. 로그인 후 [회원 초대] 메뉴로 이동합니다.
2. "직원을 초대할 매장을 하나 선택해주세요."에서 매장을 선택합니다.
3. [초대하기]로 초대코드를 발급하면 "초대코드 발급 완료"와 함께 6자리 코드가 표시됩니다.
4. 이 코드를 직원에게 전달합니다.
발급에 실패하면 "초대코드 발급에 실패했습니다. 다시 시도해주세요." 안내가 나오니 다시 시도해 주세요.

### Q. 초대코드는 어떻게 입력하나요? (직원)
본인 계정으로 로그인한 뒤 [회원 초대] 메뉴에서 [수락하기]를 누르고, 점주에게 받은 6자리 초대코드를 입력합니다. 코드가 유효하면 해당 매장에 합류됩니다.

### Q. 초대코드 유효시간이 있나요?
네. 초대코드는 발급 후 15분 동안만 유효하고, 한 번 사용되면 사라집니다(1회용). 매장마다 유효한 초대코드는 하나뿐이어서, 새로 발급하면 이전 코드는 더 이상 사용할 수 없습니다. 여러 명을 초대하려면 한 명이 합류할 때마다 새 코드를 발급해 주세요.

### Q. 초대코드를 입력했는데 오류가 나요.
- 코드가 틀렸거나 이미 사용된 코드: 존재하지 않는 코드로 처리됩니다. 점주에게 새 코드를 요청해 주세요.
- 15분이 지난 코드: "이미 만료된 초대코드입니다." 로 처리됩니다. 점주에게 재발급을 요청해 주세요.
- "초대코드 확인 중 오류가 발생했습니다. 코드를 다시 확인해주세요." → 6자리 영문 대문자·숫자 조합을 정확히 입력했는지 확인해 주세요.
