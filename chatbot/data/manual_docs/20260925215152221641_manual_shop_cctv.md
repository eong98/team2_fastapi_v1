# Allimio 매장 · CCTV 이용 매뉴얼 (매장 관리 · CCTV · 이상행동 이슈 · 손님 내역 · 캘린더 · 도면)

이 문서는 Allimio(올리미오, all-im-io) AI CCTV 관제 서비스에서 매장과 CCTV 관련 기능을 이용하는 방법과 정책을 질문-답변 형태로 정리한 안내서입니다. 각 항목은 독립적으로 읽어도 이해되도록 작성되었습니다.

---

## 0. 어디서 하나요? (매장·CCTV 기능 위치 안내)

### Q. 매장·CCTV 기능은 각각 어디서 하나요? (위치 한눈에 보기)
모두 로그인 후 왼쪽 메뉴(사이드바)에서 들어갑니다. CCTV·이슈·손님 내역·캘린더는 상단 바에서 매장을 먼저 선택해야 합니다.
| 하고 싶은 일 | 위치 | 주소 |
|---|---|---|
| 내 매장 목록 보기 | 왼쪽 메뉴 [매장 목록] 또는 상단 바 매장 선택 → [매장 전체 관리] | /user/shop |
| 매장 등록 | 매장 목록 화면 [+ 매장생성] | /user/shop/new |
| 매장 수정 | 매장 목록의 매장 카드 [수정] | /user/shop/(매장번호)/edit |
| 매장 삭제 | 매장 수정 화면 하단 [매장 삭제] | /user/shop/(매장번호)/edit |
| 매장 길찾기 | 매장 목록의 매장 카드 [길찾기] | /user/shop |
| 매장 전환(선택) | 상단 바 매장 이름 클릭 → 목록에서 선택, 또는 매장 카드 [입장하기] | 모든 /user 화면 |
| CCTV 목록 보기 | 왼쪽 메뉴 [CCTV 목록] 또는 매장 카드 [CCTV 보기] | /user/cctv |
| 이상행동 이슈 확인·정탐/오탐 처리 | 왼쪽 메뉴 [CCTV 이슈 내역] → 이슈 [보기] | /user/cctvissue |
| 특정 CCTV의 이슈만 보기 | CCTV 목록에서 해당 CCTV [이슈 보기] | /user/cctvissue?cno=(CCTV번호) |
| 이슈 증빙 파일 첨부 | CCTV 이슈 내역 → 이슈 [보기] → 상세 패널의 첨부 영역 | /user/cctvissue |
| 손님 출입·체류 내역 | 왼쪽 메뉴 [CCTV 손님 내역] | /user/cctvvisitor |
| 매장 일정 관리 | 왼쪽 메뉴 [매장 캘린더] → [+ 일정 등록] | /user/calendar |
| 매장 도면 등록·변경 | 왼쪽 메뉴 [매장 도면 관리] | /user/shopmap |
| 직원 초대 | 왼쪽 메뉴 [회원 초대] | /user/invite |
| CCTV 등록·설정 변경 요청 | 고객센터 1:1 문의 (상단 [문의하기]) | /user/qa/new |

### Q. 로그인 후 화면은 어떻게 구성되어 있나요? (메뉴 위치)
로그인하면 사용자 관리 화면(주소 /user)으로 들어갑니다.
- 왼쪽 메뉴(사이드바): 매장 목록, CCTV, 이슈, 손님 내역, 캘린더, 도면, 알림, 회원 초대 등 기능 메뉴가 있습니다. 사이드바 맨 아래에 [마이페이지]와 [로그아웃]이 있습니다. 모바일에서는 상단의 메뉴 버튼(전체 메뉴 열기)을 눌러 사이드바를 엽니다.
- 상단 바: 현재 선택한 매장 이름이 표시되고, 누르면 내 매장 목록이 펼쳐져 바로 다른 매장으로 전환할 수 있습니다. 목록 아래 [매장 전체 관리]를 누르면 매장 목록 화면으로 이동합니다.
메뉴에서 기능을 찾기 어려우면 아래 "어디서 하나요" 항목의 주소를 브라우저 주소창에 입력해도 됩니다. 로그인하지 않은 상태에서 /user 주소로 들어가면 로그인 화면으로 이동합니다.

### Q. 매장 등록은 어디서 하나요?
왼쪽 메뉴의 [매장 목록](/user/shop) 화면 상단의 [+ 매장생성] 버튼을 누르면 매장 등록 화면(/user/shop/new)이 열립니다. 상단 바 매장 선택 목록 아래의 [매장 전체 관리]로도 매장 목록 화면에 갈 수 있습니다.

### Q. 매장 정보 수정·삭제는 어디서 하나요?
[매장 목록](/user/shop)에서 해당 매장 카드의 [수정] 버튼을 누르면 매장 수정 화면이 열립니다. 삭제는 매장 수정 화면 맨 아래의 [매장 삭제] 버튼에서 합니다. 매장 목록 화면에는 삭제 버튼이 없습니다.

### Q. 매장 선택(전환)은 어디서 하나요?
로그인 후 모든 화면 상단 바에 현재 매장 이름이 표시됩니다. 매장 이름을 누르면 내 매장 목록이 펼쳐지고, 원하는 매장을 누르면 그 자리에서 바로 전환됩니다. 또는 [매장 목록](/user/shop)에서 매장 카드의 [입장하기]를 눌러도 됩니다.

### Q. CCTV 목록은 어디서 보나요?
왼쪽 메뉴의 [CCTV 목록](/user/cctv)에서 봅니다. 매장 목록의 매장 카드에서 [CCTV 보기]를 누르면 해당 매장이 선택된 상태로 바로 이동합니다.

### Q. CCTV 이슈(이상행동) 확인과 정탐/오탐 처리는 어디서 하나요?
왼쪽 메뉴의 [CCTV 이슈 내역](/user/cctvissue)에서 합니다. 목록에서 이슈의 [보기]를 누르면 오른쪽에 상세 패널이 열리고, 패널 하단의 [정탐 확인] / [오탐 처리] 버튼으로 처리합니다. 증빙 파일 첨부도 같은 상세 패널에서 합니다. 특정 CCTV의 이슈만 보려면 [CCTV 목록]에서 그 CCTV의 [이슈 보기]를 누르세요.

### Q. 손님 출입 내역은 어디서 보나요?
왼쪽 메뉴의 [CCTV 손님 내역](/user/cctvvisitor)에서 봅니다. 상단 바에서 매장을 먼저 선택해야 합니다.

### Q. 매장 캘린더(일정)는 어디서 관리하나요?
왼쪽 메뉴의 [매장 캘린더](/user/calendar)에서 관리합니다. 화면 상단 [+ 일정 등록] 버튼으로 일정을 추가하고, 캘린더의 일정을 눌러 수정·삭제합니다.

### Q. 매장 도면은 어디서 등록하나요?
왼쪽 메뉴의 [매장 도면 관리](/user/shopmap)에서 매장별로 [등록] / [변경] / [도면 삭제] / [도면 보기]를 합니다. 등록·변경·삭제는 점주만 가능합니다.

### Q. CCTV를 추가하거나 설정을 바꾸려면 어디에 요청하나요?
사용자 화면에는 CCTV 추가·수정 메뉴가 없습니다. 메인 화면 상단 [문의하기](로그인 상태: /user/qa/new)로 고객센터 1:1 문의를 남겨 주세요.

## 1. 기본 개념 · 권한

### Q. Allimio는 어떤 서비스인가요?
Allimio는 무인 매장(스터디카페, 무인 편의점 등)에 설치된 CCTV 영상을 AI가 분석해 폭행, 기물파손, 쓰러짐, 무단침입, 장시간체류 같은 이상행동을 감지하고 점주에게 알려 주는 관제 서비스입니다. 점주는 매장을 등록하고, 매장별 CCTV와 이상행동 이슈, 손님 출입 내역, 매장 일정, 매장 도면을 한곳에서 관리합니다.

### Q. 점주와 직원은 무엇이 다른가요?
- 점주(구독권을 구매한 회원): 본인이 등록한 매장을 소유하고 관리합니다. 매장 생성·수정·삭제, 직원 초대, 매장 도면 등록·변경·삭제를 할 수 있습니다.
- 직원: 점주에게 초대코드를 받아 매장에 합류한 회원입니다. 배정된 매장만 볼 수 있으며, CCTV·이슈·손님 내역·캘린더를 확인하고 이용할 수 있습니다. 매장 도면은 조회만 가능하고 직원 초대는 할 수 없습니다.
회원가입만 한 상태에서는 소유하거나 배정된 매장이 없어서 매장 목록이 비어 있습니다. 구독권을 구매하면 점주가 되고, 초대코드를 입력하면 해당 매장의 직원이 됩니다.

### Q. 매장 관련 메뉴는 어떤 것이 있나요?
로그인 후 왼쪽 메뉴(사이드바)에서 다음 화면을 이용합니다.
- 매장 목록(/user/shop): 내 매장 확인, 매장 생성·수정, 매장 입장
- CCTV 목록(/user/cctv): 선택한 매장의 CCTV 장비 확인
- CCTV 이슈 내역(/user/cctvissue): AI가 감지한 이상행동 확인 및 정탐/오탐 처리
- CCTV 손님 내역(/user/cctvvisitor): AI가 추적한 손님 입장·퇴장·체류시간
- 매장 캘린더(/user/calendar): 매장 일정(휴무, 이벤트, 정산, 점검 등) 관리
- 매장 도면 관리(/user/shopmap): 매장 평면도 이미지 등록·조회
- 알림 관리(/user/notification): 이상행동 알림 확인
- 회원 초대(/user/invite): 직원 초대코드 발급·입력

## 2. 매장 선택(입장)

### Q. "먼저 관리할 매장을 선택해주세요"라고 나와요.
CCTV 목록, CCTV 이슈 내역, CCTV 손님 내역, 매장 캘린더는 "현재 선택한 매장" 기준으로 보여 주는 화면입니다. 화면 상단 바의 매장 선택 목록에서 매장을 고르거나, [매장 목록]에서 원하는 매장의 [입장하기] 또는 [CCTV 보기]를 누른 뒤 다시 들어가 주세요.

### Q. 다른 매장으로 전환하려면?
화면 상단 바의 매장 선택 목록("매장을 선택해주세요")에서 다른 매장을 고르면 됩니다. 선택한 매장은 CCTV, 이슈, 손님 내역, 캘린더 등 모든 사용자 화면에 함께 적용됩니다. [매장 목록]에서 다른 매장의 [입장하기]를 눌러도 전환됩니다.

### Q. 매장 목록에 내 매장이 안 보여요.
- 점주: 본인이 등록한 매장만 보입니다. 아직 매장을 생성하지 않았다면 [+ 매장생성]으로 등록해 주세요.
- 직원: 초대코드로 합류한 매장만 보입니다. 매장이 안 보이면 점주에게 초대코드를 다시 받아 [회원 초대] 메뉴에서 입력해 주세요.
- 검색어나 필터가 걸려 있으면 [초기화]를 눌러 주세요.
- 회원 등급 변경(구독권 구매 등) 직후라면 로그아웃 후 다시 로그인해 주세요.

## 3. 매장 목록 · 매장 등록/수정/삭제

### Q. 매장 목록 화면에서는 무엇을 할 수 있나요?
[매장 목록]에서는 내 매장을 카드 형태로 확인합니다. 카드마다 매장명, 등록 CCTV 대수가 표시되고 다음 버튼이 있습니다.
- [입장하기]: 해당 매장을 선택하고 매장 관제 화면(대시보드)으로 이동
- [수정]: 매장 정보 수정 화면으로 이동
- [CCTV 보기]: 해당 매장을 선택하고 CCTV 목록으로 바로 이동
- [길찾기]: 매장 주소로 카카오맵 검색을 새 탭으로 열기
매장명·주소로 검색할 수 있으며, 검색어 입력 후 [검색]을 눌러야 적용됩니다. 목록은 최근 등록순으로 정렬됩니다.

### Q. 매장은 어떻게 등록하나요?
[매장 목록]에서 [+ 매장생성]을 누르면 매장 등록 화면이 열립니다.
- 매장명 (필수, 예: 본점 · 스터디카페 A)
- 우편번호 / 주소 (필수): [우편번호 검색] 버튼으로 검색하면 자동 입력되며 직접 입력할 수 없습니다.
- 상세주소: 동/호수 등
- 매장연락처 (예: 02-1234-5678), 핸드폰 (예: 010-1234-5678)
- 사업자등록번호 (예: 123-45-67890)
- 특이사항: 매장 운영 관련 메모
입력 후 저장하면 매장 목록에 추가됩니다. 등록 후에도 언제든 수정할 수 있습니다.

### Q. 매장 등록 시 "매장명을 입력해주세요" / "우편번호 검색으로 주소를 입력해주세요"가 나와요.
매장명과 주소는 필수 항목입니다. 매장명을 입력하고, 주소는 [우편번호 검색]을 눌러 검색 결과에서 선택해 주세요. 우편번호 검색 창이 뜨지 않고 "우편번호 검색 스크립트를 불러오지 못했습니다." 안내가 나오면 페이지를 새로고침한 뒤 다시 시도해 주세요.

### Q. 매장 저장 시 "저장 권한이 없습니다. 다시 로그인 해주세요."가 나와요.
로그인이 만료된 상태입니다. 로그아웃 후 다시 로그인한 뒤 저장해 주세요. "네트워크 오류가 발생했습니다." 또는 "저장에 실패했습니다."가 나오면 잠시 후 다시 시도해 주세요.

### Q. 매장 정보는 어떻게 수정하나요?
[매장 목록]에서 해당 매장 카드의 [수정]을 누르면 매장 수정 화면이 열립니다. 매장명, 주소, 연락처, 사업자등록번호, 특이사항을 바꾼 뒤 저장합니다.

### Q. 매장을 삭제하려면?
매장 수정 화면 하단의 [매장 삭제] 버튼으로 삭제합니다. 삭제한 매장 정보는 복구할 수 없으니 신중하게 진행해 주세요. 매장에 연결된 CCTV, 구독권, 직원이 있는 경우 삭제 전에 고객센터에 먼저 문의하는 것을 권장합니다.

### Q. 매장 주소로 길찾기를 할 수 있나요?
네. [매장 목록]에서 매장 카드의 [길찾기]를 누르면 카카오맵이 새 탭으로 열리고 매장 주소가 검색됩니다. 좌표가 아닌 주소 검색 방식이므로 검색 결과에서 정확한 위치를 선택해 주세요. 주소가 등록되지 않은 매장은 "등록된 주소가 없어 길찾기를 열 수 없습니다."가 표시됩니다.

### Q. 매장은 몇 개까지 등록할 수 있나요?
매장 등록 개수 자체에는 별도 제한이 없습니다. 다만 관제 서비스를 이용하려면 매장마다 구독권이 연결되어 있어야 하며, 구독권은 CCTV 대수에 따라 요금이 달라집니다. 구독권 관련 내용은 구독권(요금제) 안내를 참고해 주세요.

## 4. CCTV 목록 · 장비

### Q. CCTV는 누가 등록하나요? 직접 추가할 수 있나요?
CCTV 장비 등록은 Allimio 관리자가 설치·연결 작업과 함께 처리합니다. 점주나 직원이 사용자 화면에서 CCTV를 직접 추가·삭제할 수는 없습니다. "등록된 CCTV가 없습니다. 관리자에게 CCTV 등록을 요청해주세요." 안내가 보이면 고객센터 1:1 문의로 CCTV 등록을 요청해 주세요.

### Q. CCTV 목록에서는 무엇을 볼 수 있나요?
[CCTV 목록]은 현재 선택한 매장의 CCTV를 보여 줍니다.
- CCTV명
- MAC 주소: 장비 고유 식별 번호
- 대표: 매장의 대표 카메라 여부 (매장 카드 미리보기 등에 사용)
- 상태: 정상 / 점검중 / 고장
- 최근 점검일
- 등록일
CCTV명 또는 MAC 주소로 검색할 수 있습니다. 각 CCTV의 [이슈 보기]를 누르면 그 CCTV에서 감지된 이슈만 모아서 볼 수 있습니다.

### Q. CCTV 상태가 "점검중" 또는 "고장"으로 나와요.
- 정상: 영상 분석이 정상적으로 이루어지는 상태입니다.
- 점검중: 관리자가 장비를 점검하고 있는 상태로, 이 기간에는 이상행동 감지가 원활하지 않을 수 있습니다.
- 고장: 장비 또는 연결에 문제가 있는 상태입니다. 전원·네트워크 연결을 확인하고, 해결되지 않으면 고객센터로 A/S를 요청해 주세요.

### Q. CCTV 영상 연결이 안 돼요 / 연결 상태는 어디서 보나요?
CCTV 영상은 카메라의 스트림 주소(RTSP 등)로 연결되며, 연결 상태는 미연결 / 연결됨 / 오류로 관리됩니다. 연결 정보 설정과 재연결은 관리자가 처리합니다. 영상이 보이지 않거나 이슈 감지가 멈춘 것 같으면 매장의 인터넷과 카메라 전원을 먼저 확인한 뒤 고객센터로 문의해 주세요.

### Q. CCTV 이름이나 설정을 바꾸고 싶어요.
CCTV명, 대표 카메라 지정, 점검일 등 장비 정보 변경은 관리자가 처리합니다. 고객센터 1:1 문의로 매장명과 변경할 CCTV(MAC 주소 또는 CCTV명), 원하는 내용을 알려 주세요.

## 5. CCTV 이슈 (AI 이상행동 감지)

### Q. AI가 감지하는 이상행동은 어떤 것이 있나요?
| 유형 | 감지 기준 | 심각도 |
|---|---|---|
| 폭행 | 사람 간 신체적 폭력으로 보이는 격한 접촉이 감지될 때 | 높음 |
| 기물파손 | 매장 집기·설비가 파손된 것으로 보이는 변화가 감지될 때 | 보통 |
| 쓰러짐/응급 | 사람이 쓰러지거나 응급 상황으로 보이는 자세가 감지될 때 | 높음 |
| 무단침입 | 영업시간 외에 매장 안에서 사람이 감지될 때 | 보통 |
| 장시간체류 | 한 사람이 매장에 비정상적으로 오래 머무를 때 | 낮음 |
AI는 카메라 영상 속 사람의 위치·자세·움직임을 분석해 판단합니다. 세부 감지 기준은 보안을 위해 공개하지 않으며, 운영 정책에 따라 추가되거나 변경될 수 있습니다.

### Q. 무단침입 기준이 되는 영업시간을 우리 매장에 맞게 바꿀 수 있나요?
현재 무단침입 판정에 쓰이는 영업시간은 모든 매장에 공통 기준이 적용되며, 매장별로 영업시간을 설정하는 기능은 아직 없습니다. 우리 매장 영업시간과 맞지 않아 24시간 운영 매장 등 다른 영업시간이 필요하면 고객센터 1:1 문의로 알려 주세요.

### Q. 쓰러진 사람이 있었는데 기물파손 알림은 안 왔어요.
정상입니다. 사람이 쓰러지거나 폭행 상황이 진행 중일 때는 그로 인한 화면 변화를 기물파손으로 중복 알리지 않습니다. 그 상황이 끝나고 잠시 뒤에도 매장 모습이 바뀐 채 남아 있으면 기물파손으로 따로 감지됩니다.

### Q. 이상행동이 감지되면 어떻게 알 수 있나요?
AI가 이상행동을 감지하면 CCTV 이슈가 저장되고, AI 감지 신뢰도가 서비스 기준 이상이면 매장 점주와 소속 직원 모두에게 알림(서비스 내 알림, 이메일, 문자)이 발송됩니다. 매장 도면이 등록되어 있으면 도면 위에 발생 위치를 표시한 이미지도 함께 제공됩니다. 알림 발송 여부는 이슈의 "발송여부"(발송완료/미발송)로 확인할 수 있고, 모든 이슈는 [CCTV 이슈 내역]에서 다시 볼 수 있습니다.

### Q. CCTV 이슈 내역은 어떻게 보나요?
[CCTV 이슈 내역]에서 현재 선택한 매장의 이슈를 최신순으로 확인합니다. 목록에는 번호, 유형, 발생일시, 신뢰도, 오탐여부, 발송여부, 상황설명이 표시됩니다. 다음 조건으로 걸러 볼 수 있습니다.
- 유형 (폭행, 기물파손 등)
- 오탐여부 (미확인 / 정탐 / 오탐)
- 발송여부 (발송완료 / 미발송)
- 발생일 기간 (시작~종료)
- 상황설명 검색어
[CCTV 목록]에서 특정 CCTV의 [이슈 보기]로 들어오면 그 CCTV의 이슈만 표시됩니다.

### Q. 이슈 상세에는 어떤 정보가 있나요?
이슈의 [보기]를 누르면 오른쪽에 "CCTV 이슈 상세" 패널이 열립니다. CCTV 번호, 발생 일시, 유형, AI 감지 신뢰도, 상황설명, 오탐여부, 처리담당자, 처리일시, 발송여부와 증빙 첨부파일을 확인할 수 있습니다.

### Q. 신뢰도는 무엇인가요?
AI가 해당 상황을 그 유형의 이상행동이라고 판단한 확신 정도(%)입니다. 신뢰도가 서비스 기준 이상인 이슈만 알림이 발송되고, 기준에 못 미치는 이슈는 기록만 남고 발송여부가 "미발송"으로 표시됩니다. 신뢰도가 높을수록 실제 상황일 가능성이 높지만, 신뢰도와 관계없이 영상을 직접 확인한 뒤 정탐/오탐으로 처리하는 것을 권장합니다.

### Q. 이슈 발송여부가 "미발송"이에요. 왜 알림이 안 왔나요?
AI 감지 신뢰도가 서비스 기준에 못 미치는 이슈는 알림을 보내지 않고 기록만 남기기 때문에 "미발송"으로 표시됩니다. 신뢰도가 높은데도 미발송이면 알림 대상(점주·직원)에게 이메일·문자 발송이 모두 실패한 경우이니, 마이페이지의 이메일·연락처를 확인하고 고객센터로 문의해 주세요.

### Q. 정탐, 오탐, 미확인은 무슨 뜻인가요?
- 미확인(미처리): AI가 감지했지만 아직 사람이 확인하지 않은 이슈입니다.
- 정탐: 실제로 이상행동이 있었다고 확인한 이슈입니다.
- 오탐: AI가 잘못 감지한 이슈(실제 상황 아님)입니다.
오탐으로 처리된 내역은 AI 감지 품질 개선에 활용됩니다.

### Q. 이슈를 정탐/오탐으로 처리하려면?
[CCTV 이슈 내역]에서 이슈의 [보기]를 눌러 상세 패널을 연 뒤 하단의 [정탐 확인] 또는 [오탐 처리]를 누릅니다. "처리 결과가 저장되었습니다." 안내가 나오면 완료입니다. 처리한 사람(로그인한 회원)이 처리담당자로, 누른 시각이 처리일시로 기록됩니다. 점주와 매장 직원 모두 처리할 수 있습니다.

### Q. 정탐/오탐을 잘못 눌렀어요. 되돌릴 수 있나요?
네. 이미 처리한 이슈도 상세 패널에서 [정탐 확인] 또는 [오탐 처리]를 다시 누르면 변경됩니다. 이때 처리담당자와 처리일시도 마지막으로 처리한 사람과 시각으로 바뀝니다.

### Q. 이슈에 사진이나 영수증 같은 증빙을 남길 수 있나요?
네. 이슈 상세 패널의 증빙 첨부파일 영역에 현장 사진, 영수증 등 파일을 올리고 [첨부파일 저장]을 누르면 "증빙 첨부파일이 저장되었습니다."가 표시됩니다. 파일 1개당 최대 10MB까지 올릴 수 있으며, 10MB가 넘는 파일은 선택되지 않습니다. 증빙 파일이 있는 이슈는 목록에 첨부 표시가 나타납니다.

### Q. 이슈 처리나 첨부 저장이 실패해요.
"처리에 실패했습니다. 다시 시도해주세요." 또는 "첨부파일 저장에 실패했습니다. 다시 시도해주세요."가 나오면 잠시 후 다시 시도해 주세요. 파일 크기(10MB)를 확인하고, 계속 실패하면 로그아웃 후 다시 로그인해 보세요.

### Q. 이슈를 삭제할 수 있나요?
사용자 화면에서는 이슈를 삭제할 수 없습니다. 이슈는 매장 보안 기록으로 보관됩니다. 잘못 감지된 이슈는 [오탐 처리]로 표시해 주세요.

### Q. 실제 사고(폭행, 응급 상황)가 감지되면 어떻게 해야 하나요?
Allimio는 상황을 감지하고 알려 주는 서비스이며, 경찰이나 119에 자동으로 신고하지 않습니다. 폭행·쓰러짐/응급처럼 심각도가 높은 알림을 받으면 영상을 확인하고 필요하면 즉시 112(경찰) 또는 119(구급)에 신고해 주세요. 확인 후에는 이슈를 [정탐 확인]으로 처리하고, 필요하면 증빙 파일을 첨부해 기록을 남겨 두세요.

## 6. CCTV 손님 내역 (출입·체류)

### Q. CCTV 손님 내역은 무엇인가요?
AI가 CCTV 영상에서 손님을 인식해 추적한 입장·퇴장 기록입니다. [CCTV 손님 내역]에서 현재 선택한 매장의 기록을 최신순으로 확인합니다. 얼굴이나 이름 같은 개인 식별 정보가 아니라 AI가 붙인 추적 번호(AI추적ID)로 구분합니다.

### Q. 손님 내역에는 어떤 정보가 나오나요?
번호, CCTV번호, AI추적ID, 입장시각, 퇴장시각, 체류시간(분), 상태, 등록일이 표시됩니다. 상태는 다음과 같습니다.
- 입장중: 아직 퇴장이 확인되지 않은 손님
- 정상퇴장: 입장 후 정상적으로 퇴장한 손님
- 장시간체류: 비정상적으로 오래 머문 손님 (장시간체류 이슈와 연계)

### Q. 손님 내역을 검색하려면?
AI추적ID 검색, CCTV번호 필터, 상태 필터, 입장일 기간(시작~종료)으로 조건을 설정한 뒤 [검색]을 누릅니다. [초기화]를 누르면 조건이 모두 해제됩니다.

### Q. 퇴장시각이 비어 있어요.
아직 퇴장이 감지되지 않은 손님(입장중)이거나, 카메라 사각지대로 나가 퇴장이 인식되지 않은 경우입니다. 퇴장이 확인되면 퇴장시각과 체류시간(분)이 채워지고 상태가 정상퇴장 또는 장시간체류로 바뀝니다. 장시간체류 여부는 AI가 체류시간을 보고 판단합니다. 같은 손님(같은 AI추적ID)은 한 번만 기록됩니다.

## 7. 매장 캘린더

### Q. 매장 캘린더는 어떤 기능인가요?
[매장 캘린더]에서 현재 선택한 매장의 일정을 월/주/목록 보기로 관리합니다. 매장에 소속된 점주와 직원이 같은 캘린더를 공유합니다. [오늘] 버튼으로 오늘 날짜로 바로 이동할 수 있습니다.

### Q. 일정 종류에는 어떤 것이 있나요?
일반, 휴무, 이벤트, 정산, 점검 다섯 가지가 있으며 종류마다 기본 색상이 다릅니다. 원하는 경우 일정마다 색상을 직접 지정할 수 있습니다.

### Q. 일정은 어떻게 등록하나요?
[+ 일정 등록]을 누르거나 캘린더에서 날짜를 선택해 등록 창을 엽니다.
- 일정 종류 선택
- 제목 (필수)
- 시작/종료 일시 (필수), 종일 여부
- 상세 메모 (선택)
- 색상 (선택)
[저장]을 누르면 등록됩니다.

### Q. 일정 저장 시 안내가 나와요.
- "제목을 입력해주세요." → 제목은 필수입니다.
- "시작/종료 일시를 입력해주세요." → 시작과 종료 일시를 모두 입력해 주세요.
- "종료 일시가 시작 일시보다 빠를 수 없습니다." → 종료 일시를 시작 이후로 설정해 주세요.
- "저장 중 알 수 없는 오류가 발생했습니다." → 잠시 후 다시 시도해 주세요.

### Q. 일정을 수정·이동·삭제하려면?
캘린더의 일정을 누르면 "일정 수정" 창이 열리고 내용을 바꾸거나 삭제할 수 있습니다. 일정을 끌어서 다른 날짜로 옮기면 날짜가 바로 변경됩니다. 이동에 실패하면 "일정 이동에 실패했습니다. 다시 시도해주세요."가 표시되고 원래 위치로 돌아갑니다.

## 8. 매장 도면

### Q. 매장 도면은 무엇에 쓰이나요?
매장 평면도 이미지를 등록해 두는 기능입니다. 등록한 도면은 이상행동 알림에서 발생 위치를 도면 위에 표시하는 데 활용됩니다.

### Q. 도면은 누가 등록할 수 있나요?
도면 등록·변경·삭제는 점주만 할 수 있습니다. 직원은 도면을 조회만 할 수 있으며, 등록을 시도하면 "도면 등록 및 변경은 점주만 가능합니다."가 표시됩니다.

### Q. 도면은 어떻게 등록·변경하나요?
[매장 도면 관리]에서 매장을 찾아(매장명·주소 검색 가능) [등록] 또는 [변경]을 누르고 도면 이미지 파일을 선택한 뒤 저장합니다. 매장당 도면은 1개이며, 변경하면 기존 도면이 새 이미지로 교체됩니다. 완료되면 "매장 도면이 등록되었습니다." 또는 "매장 도면이 변경되었습니다."가 표시됩니다. [도면 미리보기]로 등록된 도면을 크게 볼 수 있습니다.

### Q. 도면 등록 조건이 있나요?
- 이미지 파일만 등록할 수 있습니다. ("이미지 파일만 등록할 수 있습니다.")
- 최대 10MB까지 등록할 수 있습니다. ("도면 이미지는 최대 10MB까지 등록할 수 있습니다.")
- 파일을 선택하지 않으면 "등록할 도면 파일을 선택해주세요."가 표시됩니다.

### Q. 도면을 삭제하려면?
[매장 도면 관리]에서 해당 매장 도면의 [삭제]를 누르고 "도면을 삭제하시겠습니까?" 확인 창에서 확인합니다. 삭제한 도면은 복구할 수 없습니다. 도면이 없는 매장은 "삭제할 도면이 없습니다."가 표시됩니다.
